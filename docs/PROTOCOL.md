# Протокол официального клиента 4PDA (Android 1.9.43, ru.fourpda.client)

Заметки по разбору APK для совместимого iOS-клиента. Код приложения не копируется — описан только сетевой протокол.

## Транспорт
- Основной путь: **обычный TCP без TLS** на `app.4pda.to:993` (из provision, поле `d`). Без HTTP-рукопожатия —
  сразу кадры в формате WebSocket (см. ниже).
- Запасной путь: TLS на порт 443 хоста из provision (поле `w`, сейчас `appbk.4pda.to`, по умолчанию `app.4pda.ru`)
  и рукопожатие WebSocket:
  ```
  GET /ws/ HTTP/1.1
  Host: app.4pda.ru
  Upgrade: websocket
  Connection: Upgrade
  Sec-WebSocket-Key: <base64 16 байт>
  Sec-WebSocket-Protocol: app
  Sec-WebSocket-Version: 13
  ```
- Кадры WebSocket клиент шлёт **без маски** (нестандартно). Байт 0: `opcode | FIN(0x80) | RSV1(0x40, если сжато)`.
  Длина: стандартная (7 бит / 126+16 бит / 127+64 бита).
- Сжатие (RSV1): payload = 4 байта LE — длина несжатых данных, далее raw DEFLATE (уровень 6, без zlib-заголовка).
  - Клиент → сервер: каждое сообщение сжимается заново (новый Deflater, finish).
  - Сервер → клиент: **один поток DEFLATE на всё соединение** (context takeover). После данных кадра
    клиент досылает в распаковщик `00 00 FF FF`. Распаковщик пересоздаётся только при новом подключении.
- Каждый кадр — целое сообщение, фрагментация не используется. Ping (9) → ответ pong (10).
- opcode 9 — ping.

## Provision (настройки)
`GET https://gist.githubusercontent.com/aigilea/152b043823de7cfeacd06f348b78ec25/raw/provision.json`,
запасной — `https://provision.app.devapps.ru/`. JSON: `b` — базовый URL сайта, `d`, `w` — хост для WebSocket.

## Формат сообщений («Document»)
Текст, похожий на JSON, но только массивы: `[1,"str",[2,3]]`.
- Элементы: целые числа, строки в `"..."`, вложенные массивы. Без пробелов, без `null`.
- Строки в **Windows-1251**, экранирование `\\ \" \n \r \t \f \b \uXXXX`.

Запрос: `[<requestId | retry<<28>, "<2 символа команды>", ...параметры]` (id и команда — в начале).
Код команды — 2 ASCII-символа (в коде числом: младший байт — первый символ).

Ответ: `[<requestId>, <код ошибки (0 = ок)>, ...данные]`. `requestId` маскируется `& 0x0FFFFFFF`.
`requestId == 0` — серверные push-события; с ненулевым кодом — ошибка для всех ожидающих запросов (код 2 — неверный формат запроса).

## Команды (найденные)
| Код | Назначение |
|-----|-----------|
| `ah` | приветствие: `[версия "1.9.43", скин, установщик, флаг, member_id]`; код 3 — клиент устарел |
| `ma` | авторизация по сохранённому ключу: `[member_id, login_key, hidden?]` |
| `ml` | вход: `[логин, пароль, скрытый режим (0/1), число с капчи]` → `[member_id, login_key]`; код 4 — нужна капча, в данных `[url картинки]` |
| `mc` | регистрация (тоже возвращает `[member_id, login_key]`) |
| `sl` | лента новостей: `[смещение, 30, -1, категория]` → `[?, [новости]]` |
| `sa` | статья: `[id]` → поля новости + `[13]` комментарии |
| `fi` | список форумов → `[[ [id, имя, флаги (16 — категория, 32 — непрочитано), ссылка] ]]` |
| `fs` | раздел: `[id, смещение, 30]` → `[2]` имя, `[5]` объявления, `[6]` подфорумы, `[7]` всего тем, `[8]` темы `[id, название, ?, флаги, ?, дата посл., ?, автор посл.]` |
| `fr` | тема: `[id, смещение, 20, режим]` → `[2]` название, `[3]` описание, `[11]` всего постов, `[12]` посты |
| `fj` | переход к посту / новым / последним в теме |
| `fn` | объявление / правила |
| `fv` | голосование в опросе |
| `fh` | лог модерации |
| `ql` | список диалогов QMS |
| `qt` | диалог QMS |
| `qb`,`qd`,`qp` | действия в QMS |
| `mi` | профиль |
| `mr` | репутация (просмотр/изменение) |
| `mh` | история |
| `mm` | упоминания |
| `mp` | сохранение профиля, `mv` — аватар |
| `mw` | заметки/наказания |
| `mn` | счётчики непрочитанного |
| `sm` | избранное (синхронизация) |
| `tc`,`tl` | тикеты |
| `ta` | жалоба |
| `as` | скины |
| `dv` | каталог устройств |
| `fu`,`su` | загрузка вложений |

Точные параметры каждой команды уточняются по ходу реализации экранов.

## HTTP-страницы
Часть функций открывается как web: `forum/index.php?act=auth`, `act=boardrules`, `act=ticket`,
`act=rep&view=history`, `act=findpost&pid=`, `act=app-options`, `act=app-skins`.
